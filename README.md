# BuddhiMati AI Technologies — exact-reference frontend

This Angular frontend is rebuilt from the user's supplied BuddhiMati reference recording/screenshot. It keeps the dark premium visual system, compact header, gradient CTA, four principle cards, and card-based enterprise AI sections while using BuddhiMati's own content.

Contact: info@buddhimati.com
Domain: https://buddhimati.com

## Run
npm install
npm start

## Production
npm run build

Upload the contents of `dist/buddhimati-ai/browser/` to `/public_html/` on GoDaddy cPanel.

The included `.htaccess` supports Angular SPA refresh routing.
